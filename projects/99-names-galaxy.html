99 Names of Allah — 3D Galaxy

  • Tech Stack: React 19, TypeScript, Three.js, React Three Fiber, Tailwind CSS, Framer Motion, Express, Firebase, Google Gemini
  • Github URL: Project Link

An immersive WebGL experience that renders the 99 Beautiful Names of Allah (Al-Asma-ul-Husna) as stars in a living celestial galaxy. Visitors orbit, zoom, and select each name across six formation styles — Spiral, Nebula, Cluster, Wave, Supernova, and Infinity — with ambient audio drones, celestial chimes, and Arabic pronunciation.

Built with React Three Fiber and Three.js, it adds AI-powered reflections via Google Gemini, a memorization checklist with downloadable completion certificates, a recitation queue for passive listening, and cloud sync through Firebase Auth and Firestore with offline fallback — a calm, meditative way to explore the names rather than a flat list on a page.
